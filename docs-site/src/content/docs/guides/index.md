The reference pages describe one command each. These pages start from a job to
be done instead:

- **[Quickstart](/quickstart/)** — install to first verdict: pull a fixture,
  validate a migration that fails, fix it, get a PASS.
- **[rowshape in CI](/guides/ci/)** — exit codes, warn-as-fail, annotations on
  the pull request, and a complete GitHub Actions workflow.
- **[Agents & MCP](/agent/)** — `rowshape init --agent`, the MCP tools,
  and the rule that makes an agent validate before it ships a migration.
